# Push checks under lazygit's metadata environment

The local pre-push hook runs `cargo audit` and `just check`. It passes in an
ordinary shell, but lazygit supplies `OSC1717=V1` to its children. The Rust
unit-test binary inherited that host advertisement and emitted metadata into
snapshots that expect ordinary terminal output.

The defect predates this fork's work. `42a3e1a`, which added cached environment
negotiation, is an ancestor of the original fork baseline `3c2269c`.

## Reproduction

At task start `2713c82`, this command fails with exit 101:

```sh
OSC1717=V1 cargo test --bin delta
```

There are 30 failures, 526 passing tests, and eight ignored tests. Failures
include directory-diff snapshots matching the user's screenshot. The same
suite passes without the host advertisement. The two known `git2` soundness
advisories are allowed warnings and do not cause this hook failure.

## Test isolation

Unit tests now leave metadata negotiation disabled. Tests that check metadata
already inject a version-1 emitter explicitly. No test mutates the shared
process environment or its cached negotiation state.

The preceding test commit checks the actual executable in fresh child
processes. It verifies absent and unsupported host versions, plus the
supported handshake and added/deleted row identities. Those tests protect
production negotiation while the unit binary gains isolation. The existing
30 failing tests provide regression coverage for the actual failure.

The `cfg!(test)` condition is false in the production executable. The local
hook and runtime host negotiation remain enabled.

## Validation

`OSC1717=V1 just check` passes with 560 tests, eight ignored tests, and no
Clippy warnings. `OSC1717=V1 git push --dry-run origin experiments` also passes
through the unchanged pre-push hook. It does not update remote refs.

All 66 frozen production output cases match the merged executable's output
byte for byte, including configured rendering and negotiated metadata.
The release executable's hash changes, so binary identity is not claimed.
No runtime timing comparison is needed for the compile-time test branch.
The earlier integration's accepted costs, advisory deferral, and coverage
limits remain unchanged.

The [evidence](data/push-hook-2026-11-16.json) records commands, failures,
checks, source and executable identities, and output parity. Full logs and
the preceding executable are preserved under `.git/performance`.
